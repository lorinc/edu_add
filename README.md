# edu_add

Tracks and pushes two teenagers' knowledge and skill levels (one on the US curriculum, one on the UK curriculum), delivering the factual curriculum in a way that trains grounded competence skills.

| [sources/](sources/) | Reference material: school curricula and free learning resources. |
| [students/](students/) | Private per-student profiles and session logs. |
| [topics/](topics/) | Two-week topics: reading, 12 questions, tasks, self-tests, Kindle EPUBs. Parent keys are gitignored. |
